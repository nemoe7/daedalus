# `NMO902` - High "the" usage density

Tags: `style`, `conciseness`, `advisory`

Aliases: `the-density`

Parameters: `the_density_cap` (`int`; default `20`), `min_the_count` (`int`; default `3`)

This rule triggers for manual review when a prose block (paragraph, list item, blockquote, heading, or table cell) uses `"the"` at least three times and `"the"` accounts for `20%` or more of the words in that block. When a comma-separated list in a flagged block repeats leading `"the"` articles before list items, `nemoize.py --format` collapses the repeated list articles while leaving the initial `"the"` intact.

```text
Check the status, the logs, and the metrics for the worker.
```

To fix this issue, remove unnecessary `"the"` articles where meaning stays unchanged, or run `nemoize.py --format` to collapse repeated `"the"` articles across comma-separated list items on flagged lines:

```text
Check status, logs, and metrics for worker.
```

Note: Default checks report `NMO902` as `(manual review)` (`advisory`) with exit code `0`. Retain `"the"` when removing it changes specificity or meaning. When `nemoizer` is used as a proper name, write `nemoizer` in lowercase without a leading `"the"`.

Rationale: Excessive definite articles pad technical instructions and descriptions without adding information.
