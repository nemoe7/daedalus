# `NMT200` - Literal equality assertion on a measurement

Tags: `tests`, `measurements`, `blocking`

Aliases: `measurement-equality`

Flag literal equality assertions on measurement calls, properties, static measurement keys, and JavaScript toBe or toHaveCSS matchers. Flag positive numeric values and positive px strings. Exempt zero values and measurements explicitly set to the asserted value in the same test.

```text
assert check.measure(path) == 42
```

To fix this issue, rewrite the text as follows:

```text
assert check.measure(path) == EXPECTED
```

Rationale: Relational or named-constant assertions keep tests resilient to legitimate size or timing changes.
